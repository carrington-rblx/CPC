# The Conservative Party of Canada Website

Official campaign-style website for the Conservative Party of Canada.

## Features

- Homepage with hero "HOPE AGAIN", stories, plan cards, signup form, join/donate banners
- Navigation: What we've delivered | Plan for Change (dropdown) | Conservative People (dropdown) | More (dropdown)
- Brand colours: `#1c2d4e` and `#ed1937`
- Official Conservative Party of Canada logo
- Responsive design matching the structure of modern party sites

## Enable GitHub Pages

1. Go to the repository Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / (root)
4. Save

Site will be live at: https://carrington-rblx.github.io/CPC/
